# ai-history — Agent Context

AI session logging, history tracking and MCP integration.

## Purpose
Collects and unifies chat histories from Claude Code, OpenCode, Gemini CLI, Cursor,
Codex, VSCode Copilot, Warp, and Antigravity. Local-first, no cloud.

## Structure
- ai_history/ — Python Package (CLI, Web UI, MCP)
- tests/ — Pytest Suite
- docs/ — Documentation
- docker-compose.yml — Local Stack
